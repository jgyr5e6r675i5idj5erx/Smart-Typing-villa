# Smart Typing Villa V4 — Puppy Feeding Challenge + Background Music

Static website suitable for deployment as a Render Static Site.

## Render settings
- Build command: leave blank
- Publish directory: `.`
- Environment variables: none

## Features
- Existing typing modes and browser-saved progress
- Calm instrumental and upbeat gaming background music
- New Puppy Feeding Challenge with 12 progressive typing stages
- The puppy stays visible in every stage and unlocks accessories as the learner advances
- Correct letters remove matching food pieces; completed challenges trigger a dance animation and synthesized bark-like sound
- Puppy treats, stages cleared, and best streak are saved locally in the browser
- Puppy sounds can be switched off separately from background music

Keep the `audio` folder alongside `index.html`, `style.css`, and `typing.js` when deploying. Mobile browsers may require a tap on the typing input before sound can play.
